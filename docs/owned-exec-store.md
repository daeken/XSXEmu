# Owned wave32 EXEC + bounded raw store

`tools/shader-inventory/exec_store_fixture.s` is an original GFX10.3 wave32 fixture. It compares an inline unsigned constant against a host-initialized lane ordinal, intersects guest EXEC, and branches over the descriptor load, wait and stores when the mask is empty. Otherwise surviving lanes write disjoint 16-byte ranges using the bounded store subset. A separate test-only last word observes the uniform branch even when no lane stores. The fixture decoder checks the compare encoding, branch destination, fixed lane-offset instruction, exact load/wait/XOR/store register forms, and both terminators.

The descriptor view and arguments are synthetic. The Metal lowering assumes one full 32-thread SIMD group, an immutable uniform descriptor table, and a synchronous load that already satisfies this fixture's exact `lgkmcnt(0)` wait. It does not model general wait counters or guest pointers. Address arithmetic is widened and checked before any access. Compiler/API validation and CPU readback cover inactive-lane preservation, all lanes masked away by the compare, initially empty EXEC, exact and clipped descriptor extents, truncated descriptors, invalid bindings, and wrapping addresses with a valid decoy table entry.

On Apple M4, **1,088/1,088 words** across eight cases matched under Metal API/GPU validation. The same **1,088/1,088** matched after bake and strict archive replay in separate processes under API validation. Both an empty archive and replay with a different owned function were rejected, rather than compiling a fallback PSO. The original ALU, EXEC and buffer probes still pass.

Use the commands in [the owned archive probe](owned-metal-archive.md) with `--bake-exec-store-archive` and `--replay-exec-store-archive`. GPU instrumentation is unsupported for this archive mode; omit archive arguments to run the normal GPU-validated probes. Replay regenerates the owned MSL function; no `.metallib` persistence, retail ABI binding, or retail translation is claimed.
